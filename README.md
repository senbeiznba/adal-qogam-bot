# Адал қоғам AI — справочник-навигатор по Конституции 2026 (Telegram Mini App)

AI-бот на RAG: отвечает на вопросах на казахском и русском **только по официальным документам**, указывает статью и источник.
Если подтверждения в базе нет — честно сообщает об этом (п. 4.9 Положения).

## Архитектура
Telegram Mini App (static/index.html) → FastAPI (main.py) → Chroma (векторный поиск) → Gemini (ответ по найденным фрагментам)

- `ingest.py` — нарезка документов по статьям, эмбеддинги, загрузка в Chroma
- `main.py` — API `/api/chat`: проверка подписи Telegram initData, rate limit, поиск, порог релевантности, генерация
- `data/` — тексты документов и `sources.json` (название и URL первоисточника)

## Технологии
Python 3.11+, FastAPI, ChromaDB, Google Gemini (`gemini-2.5-flash`, `gemini-embedding-001`), Telegram WebApp API.

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # заполните GEMINI_API_KEY и BOT_TOKEN
python ingest.py            # один раз и после изменения документов
uvicorn main:app --reload   # http://localhost:8000
```

## Безопасность
Ключи только в `.env` (в `.gitignore`); подпись initData проверяется HMAC-SHA256; rate limit; ограничение длины запроса;
системный промпт игнорирует инструкции из вопроса; персональные данные не сохраняются.

# adal-qogam-bot — бот-навигатор по внутренней политике РК

Telegram-бот на основе RAG: находит в официальных источниках (Конституция 2026, законы, Послания, концепции)
ответ на вопрос на **русском или казахском**, ссылается на первоисточник и честно сообщает, если подтверждённой
информации нет. Проект для конкурса AI-ботов «Адал қоғам» (МУИТ).

## Возможности
- Вопросы на естественном языке (текст и **голосовые сообщения**), ответ на языке вопроса.
- Ответ **только по базе официальных документов**, со ссылкой на статью и источник; без подтверждения — «нет данных».
- **Карточка понятий** («Закон и Порядок», «Адал азамат», «Справедливый Казахстан», «Слышащее государство» и др.):
  бот отдельно проверяет, закреплено ли понятие в Конституции 2026, и называет статью (или честно сообщает, что нет).
- Кнопки: «💡 Объяснить проще» (режим простыми словами) и «📄 Текст статьи» (цитата первоисточника).
- Память диалога для коротких уточнений («а какой срок?»).
- `/quiz` — викторина по Конституции (геймификация), `/stats` — аналитика для администраторов.
- Защита от злоупотреблений: вопрос — данные, а не инструкции; вне темы — отказ.

## Архитектура

```
Telegram ─► aiogram (app/bot.py) ─► RAG (app/rag.py) ─► PostgreSQL + pgvector
                │                      │  ├─ concepts.py: проверка понятий по Конституции
            голос (ogg)                │  └─ порог релевантности → «нет данных»
                └─► Gemini (транскрибация)  └─► Gemini: эмбеддинги + генерация (app/llm.py)
```

| Компонент | Технологии | Файл |
|---|---|---|
| Frontend | Telegram-клиент (текст, голос, inline-кнопки) | `app/bot.py` |
| Backend | Python 3.11+, aiogram 3, asyncio | `app/bot.py`, `app/rag.py` |
| Database | PostgreSQL 16 + pgvector (HNSW, cosine) | `app/db.py` |
| AI | Gemini: `gemini-embedding-001` (поиск), `gemini-3.8-flash` (ответ, голос) | `app/llm.py` |
| Загрузка знаний | Нарезка по статьям, эмбеддинги, метаданные (документ, раздел, ссылка) | `app/ingest.py` |
| Контроль качества | Набор вопросов с ожидаемыми ответами | `tests/`, `app/evaluate.py` |

Таблицы БД: `documents` (источники), `chunks` (фрагменты + вектор), `query_log` (аналитика).

## Логика ответа
1. Определяется язык вопроса (kk/ru); короткие уточнения дополняются предыдущим вопросом.
2. Эмбеддинг вопроса → top-K фрагментов из pgvector.
3. Фрагменты с дистанцией > `MAX_DISTANCE` отбрасываются. Если ничего не осталось — ответ «нет данных» без обращения к LLM.
4. Для известных понятий отдельно ищется упоминание в Конституции 2026 (раздел/статья или «не найдено»).
5. LLM получает только найденные фрагменты и обязан отвечать по ним со ссылками [n]; если ответа нет — `NO_INFO`.
6. Ответ очищается от Markdown, добавляется список источников; запрос пишется в `query_log`.
7. Надёжность: повторы при перегрузке API, запасная модель, понятные сообщения об ошибках.

## Запуск
```bash
cp .env.example .env            # заполнить TELEGRAM_BOT_TOKEN, GEMINI_API_KEY, DATABASE_URL
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# база: Docker (docker compose up -d) или облачный PostgreSQL с pgvector (например, Neon)
# документы положить в data/sources/ (см. data/sources/README.md)
python -m app.ingest            # загрузка базы знаний
python -m app.bot               # запуск бота
python -m app.evaluate          # проверка качества на тестовых вопросах
```

## Безопасность
- Секреты только в `.env` (в `.gitignore`), в репозитории — `.env.example`.
- Ответы строго из базы источников; без подтверждения — отказ отвечать, без домыслов.
- Защита от prompt injection, ограничение длины вопроса, обработка ошибок API/БД.
- `/stats` доступна только `ADMIN_IDS`. В `query_log` хранятся id пользователя Telegram и текст вопроса.
